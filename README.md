### Ejemplo: Practicar Algoritmos

```bash
# 1. Crear archivo para el algoritmo
touch algorithms/sorting/quick_sort.py

# 2. Implementar
cat > algorithms/sorting/quick_sort.py << 'EOF'
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

if __name__ == "__main__":
    print(quick_sort([3, 6, 8, 10, 1, 2, 1]))
EOF

# 3. Ejecutar
python algorithms/sorting/quick_sort.py
```

## Complejidad Temporal de Algoritmos

| Algoritmo | Mejor | Promedio | Peor | Espacio |
|-----------|-------|----------|------|---------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) |
| Binary Search | O(1) | O(log n) | O(log n) | O(1) |
| BFS/DFS | O(V+E) | O(V+E) | O(V+E) | O(V) |
| Dijkstra | O(V²) | O((V+E)log V) | O(V²) | O(V) |
